## Coding decisions

- Sample label: the paper prints no code for the mesoporous carbon; it is named "mesoporous carbon" throughout (curve letters change between figures: Fig. 4 curve b, Fig. 7 curve c), so the label used is `mesoporous carbon`. Only this sample has rows, so it is S1.
- `material_class = templated_carbon`, `synthesis_method = template_synthesis`: the paper describes the carbon as positively replicating "the mesostructure of the silica template" after HF removal of the silica. The paper also calls the route a "direct synthesis", so `carbonization` is the alternative reading.
- `measurement_method = volumetric_sieverts` (ASAP 2010 analyzer); the basis is never named, so `uptake_type = unspecified`, `basis_stated = false`, `basis_inferred = excess` (volumetric default).
- "a pore volume of 0.50 cm3 g-1" is stored in `total_pore_volume_cm3_g`, although the paper does not call it total; method unspecified, probe N2.
