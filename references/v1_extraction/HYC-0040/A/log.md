## Coding decisions

- Sample numbering: GO is described (synthesis, XRD d = 0.7 nm, TGA, Raman) but has no H2 value and no row, so S1-S3 number only the samples with rows, in order of first appearance of their uptake.
- Basis: the paper never names excess, absolute or total for its own data (the words appear only for literature values). `basis_stated = false`, `uptake_type = unspecified`, `basis_inferred = excess` by the Sieverts default (GRC admits a known amount of gas and follows the pressure drop; the abstract says "Sieverts apparatus").
- wt% convention: Eq. 2 on p.6 defines wt.%H = m(H2) / (m(sample) + m(H2)) x 100, so W2, source `stated`, on all wt% values including digitized points.
- `instrument_identified = true`: the paper prints the manufacturer and a named product, "Gas Reaction Controller (GRC), Advanced Materials Corporation, USA", with no further model number. Borderline; the alternative coding is `false`. `calibration_described = false`: standards (LaNi5 at 298 K, basolite C-300 at 77 K) and a leak check are named, the free-volume determination is not.
- Pore data: Table S2 "pore volume" has no stated type or method, stored as `total_pore_volume_cm3_g` for B-rGO (0.98) and Ni-B-rGO (0.36). The rGO value 4.1 cc/g exceeds the schema bound of 3 cm3/g and is not stored (it is in `notes`). `pore_volume_probe_gas = N2` because the pore size distribution belongs to the N2 isotherms (Fig. S1); methods are `unspecified` (BJH is named only for the pore size distribution). Pore sizes converted from A to nm.
- `material_class`: B-rGO `doped_carbon`; Ni-B-rGO `composite` (Ni nanoparticles, XRD after H2 reduction shows C and Ni) with B as dopant; Ni loading and B content are not stated.
- rGO 298 K (M35): printed "0" in Table 1, "negligible" in the text, "rGO-no storage" in the Fig. 8(iii) legend with no curve. Stored as 0 with `uptake_bound = approximate`; pressure 20 bar from the Table 1 caption.
- Merge of printed values with plotted points: the figure ties each printed value to the highest-pressure marker with a labelled drop line, so the printed value is that point (rule: the paper marks it). The printed pressure (20 bar) is stored; the plotted points sit at 20.3-21.0 atm (20.5-21.3 bar) and for rGO 77 K the second-highest marker (M32, 20.11 bar) is closer to 20 bar. M32 stays a separate digitized row.
- Pressure: text and captions say bar, the Fig. 8 axes say atm. Digitized pressures are atm x 1.01325; printed pressures (20 bar) are used as printed.
- Degas: 100 C (p.6) and 12 h (general PCI procedure, p.3); no end pressure (pressure "increased from 10^-3 atm to 20 atm" is the dosing range). Sample mass "Nearly 200 mg" stored as 200 for all samples. No uncertainty, error bars or repeat isotherms: `replicates_reported = false`.
- `measuring_lab_id`: Flamina group, Indian Institute of Technology, Kanpur (corresponding author A. Flamina, first affiliation). The H2 measurement is not attributed to another laboratory.
