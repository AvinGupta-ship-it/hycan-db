## Coding decisions

- Basis: the paper calls its buoyancy-corrected values "absolute" (SI p.S7), using skeletal plus N2 total-pore volume (rho_c = 1/(1/1.5 + V_total)). It names but does not define the basis, so basis_stated = false and basis_inferred = absolute for Table 1, Figure 5 and inset rows. Figure S5 is captioned "Total" while the general correction is called "absolute", so S5 rows are uptake_type total, basis_inferred unknown. Figure S6 0.17/0.34 g/cm3 have no named basis and a correction density below the skeletal density, so they are coded unknown. Figure S6 1.5 g/cm3 is a skeletal-density buoyancy correction, so it is coded excess by the instrumental default. The text values follow their curves.
- replicates_reported = true for 10Xc-60 only: two distinct 0-1 bar H2 runs are reported (Figure 5 inset and Figure S5a, with different pressure points). No uncertainties are reported anywhere.
- average_pore_diameter_nm = 1.2 nm for all samples: the printed 12 A NLDFT peak, which the text calls the major micropore size of all carbons. pore_volume_method = t_plot (V_micro); V_total is single-point at P/P0 = 0.995 (in notes).
- bet_consistency_criteria_stated = false: SI S3 states R > 0.999 and positive C but does not say consistency criteria were applied.
- Figure S6 curves are reprocessings of the same 10Xc-70 run as Figure 5 (I4). Each gets its own isotherm_id because the values differ at the same pressures.
