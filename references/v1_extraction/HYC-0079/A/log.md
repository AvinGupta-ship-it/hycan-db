## Method notes

- Calibrations (pixel index on main-6.png, from tick rows and columns, third tick as check). Figure 9: x 814.52 = 0 bar, 1058.52 = 50 bar, check 961.0 = 30 (0.055%); left y 405.05 = 0, 154.46 = 2.0 wt%, check 279.48 = 1.0 (0.22%); right y 405.05 = 0, 154.46 = 0.3 wt%, check 279.48 = 0.15 (0.22%). Figure 10: x 816.42 = 0, 1056.50 = 50, check 960.47 = 30 (0.001%); left y 807.74 = -1.0, 558.60 = 2.0, check 641.57 = 1.0 (0.09%); right y 808.0 = 0, 558.60 = 0.3, check 641.57 = 0.2 (0.10%).
- `digitize_figure.py extract --mode markers` run directly on the page image isolated only 4 of 14 NCCR-41 markers (hollow markers overlapped by fit lines and by other series). Marker centres were therefore located with hue-separated, frame-clipped template fits (legend markers as templates; V-apex fits for the CMK-1 triangles; edge markers from visible fragments), checked on overlays, then drawn as small blobs in the series colour on blank images (work/blobs/) and passed through the tool with `--mode markers --open-px 0 --no-roi`. The archives' source_image is therefore that derived image, not the page; archived centroids reproduce the fitted centres within 0.2 px. The tool's marker count equals the intended count for all 12 series (14, 1, 14, 1, 12, 1, 17, 1, 11, 1, 15, 1).
- The tool's stated-value check could be run only for NCCR-41 77 K (failed, above). Single-point 298 K archives cannot be checked (the tool needs a pressure inside a multi-point range) and the paper states no other values to check against, so the other eleven archives stay `unchecked`. Informal comparison: NCCR-41 298 K digitized 0.277 wt% at 50.41 bar vs printed 0.29 wt% at 50 bar (-4.5%).
- 1 px is about 0.012 wt% on the Figure 10 left axis and 0.008 wt% on the Figure 9 left axis; marker centres in the heavily overlapped arch regions are good to about 1-1.5 px.
