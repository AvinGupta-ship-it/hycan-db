None is visible on the page image (the upper right of the plot is empty), the caption says only "measured at 77 K for the microporous carbon sample N-C-2", and the plot has just two circle series. The legend does suggest one series is a desorption branch, but the page image gives no marker-to-label mapping, so branch was not assigned: both series are coded adsorption (the default), as separate isotherms I1 and I2, with replicates_reported false. If the legend is genuine, one series is the desorption branch of the other's run and should be recoded.

## Coding decisions worth a second look
- Sample mass: "At least 100 mg of adsorbent was used in each experiment" is a lower bound, so sample_mass_mg is empty. H2: "UHP-grade", so h2_purity_pct is empty. calibration_described is false: the paper says "calibrated volumes" and that helium was used for all measurements, but not how the free volume was determined.
- instrument_identified is true for the 77 K and Table 1 rows (PCTPro-2000, Hy-Energy Scientific Instruments; Micromeritics ASAP 2010) and false for the two RT rows, because the paper names the PCTPro for "high pressures and low temperatures (77 K)" and does not say which instrument made the room-temperature runs.
- measuring_lab_id: corresponding author marked is Meisner (footnote 3); first affiliation names no university, so "General Motors R&D Center".
- Degassing "120 C under vacuum for 12 h before testing" applies to all H2 measurements; no end pressure given.
- uptake_type is excess for Table 2, Figures 3 and 8 and the related text (the word "excess" is used but the basis is never defined, so basis_stated false, basis_inferred excess); wt% convention is never defined, so unknown with source none. No uncertainties or replicates are printed.
- Table 2 rows other than C-1 and C-4 have a single 77 K value and no isotherm id; Table 1 values have no isotherm id (for N-C-2, no plotted point lies within 2% of 1.13 bar and the value comes from a different instrument).
- Table 2 prints C-12 and C-16 with the same BET area (1627 m2 g-1); copied as printed.
