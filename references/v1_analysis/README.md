# v1.0 analyses (protocol §11)

This directory holds the §11 analysis outputs, each generated by
`scripts/v1_search/analysis.py` from the assembled dataset
(`data/processed/measurements_v1.0_computed.csv`); rerun the script to
regenerate them. Numbers live in the JSON files, not in this README.

| File | Content |
|---|---|
| `rq1_samples.csv` | The RQ1 primary analysis units (`hycan.v1_sets.rq1_samples`): one n_ex,max per sample with its laboratory and §11.0-eligible BET area. |
| `rq1.json` | RQ1: the primary mixed-model ratio to A_BET/500 with the t-based and laboratory-bootstrap 95% CIs, the §11 decision against [1/1.15, 1.15], the 95% prediction interval and variance components; the secondary ln–ln slope with reliability-corrected estimates; the exclusion ladder from all coded 77 K excess isotherms to the primary set; and the `p_at_nmax_bar` distribution with every value outside 10–60 bar listed. |
| `rq1_sensitivity.json` | The RQ1 sensitivity analyses (i)–(xiii): (i)–(x) the primary model on the changed set, each with whether its decision differs from the primary; (xi) leave-one-laboratory-out; (xii) the §7 design-weighted mean (weights N_h/d_h; MixedLM takes no sampling weights, so the estimator is the weighted mean of y with the laboratory-cluster bootstrap CI); (xiii) the v0.1 specification (`hycan.meta.chahine_mixedlm` on `hycan.meta.chahine_subset`, unchanged since commit 45c669a) on all rows of the probability-sample papers. |
| `rq1_moderator_frame.csv` | The RQ1 samples with the §11 moderator columns (`hycan.v1_sets.moderator_frame`; aggregation rules in its docstring — V_micro/V_total strictly N₂-probe). |
| `rq1_moderators.json` | Each moderator added alone to the primary model, then all together on the complete cases; material classes under 5 papers merged into `other`; categorical references are the most frequent level; all exploratory. |
| `rq2_samples.csv` | The RQ2 analysis units (`hycan.v1_rq2.rq2_samples`): the §11.0 sample rule applied to the 0.9–1.2 bar window. |
| `rq2.json` | RQ2 models (a)–(c) on the probability sample and on all §4-eligible papers (§7's pre-specified secondary analysis); the BET-vs-V_micro comparison on the samples that carry both, with ML AIC. |
| `material_identity_map.csv` | Every distinct `material_identity` string mapped to a material key for RQ3. Strings merge only when their printed product designations are identical modulo trivial formatting (AX-21/AX21; a typo such as PICATIF for PICACTIF), or one string merely adds supplier detail; different designations never merge (Maxsorb-3, Maxsorb 3000, MSC-30 and bare Maxsorb stay distinct). Prepared by the AI assistant and reviewable row by row; the `note` column carries each merge's reason. |
| `rq3_values.csv` | One row per material key, quantity and laboratory (`hycan.v1_rq3.rq3_values`): the laboratory's geometric-mean A_BET, n_ex,max, 1-bar uptake and n_ex,max/(A_BET/500). |
| `rq3.json` | Per-material between-laboratory CVs with χ²-based 95% CIs, and the pooled SD per quantity (within-material one-way ANOVA; `hycan.v1_rq3` docstring). |
| `rq4_items.csv` | The RQ4 paper-level items (a)–(j) over the probability sample (`hycan.v1_rq4.paper_items`; item rules in its docstring). |
| `rq4.json` | The §7-weighted stratified ratio estimates with Korn–Graubard 95% CIs, overall and by publication period. |
| `rq5_rows.csv` | The RQ5 target rows with features (`hycan.v1_rq5.rq5_rows`). |
| `rq5.json` | RQ5 models (a)–(c): pooled out-of-fold R² and MAE over 20 GroupKFold partitions by paper (mean and 2.5–97.5 percentiles), the paper-level bootstrap CI on partition 0, and the by-laboratory and row-weighted sensitivities; on the probability sample and on all §4-eligible papers. |

Known limitations, disclosed here and wherever the affected result is
reported:

- **RQ3 counts laboratories as coded.** `kansai-maxsorb-3` enters with two
  laboratories (HYC-0084, Zhao 2018; HYC-0075, Chen 2019 — both Fujian
  Agriculture and Forestry University) whose printed values are identical
  (2.1 wt% at 1 bar, 5.8 wt% at 4 MPa/40 bar, A_BET 3203 m² g⁻¹). Both
  papers present the values as their own measurement and neither cites the
  other, so `duplicate_of` does not apply and they stand as two
  laboratories; if they are in fact one measurement, that material's CV of
  0 understates dispersion.
- **RQ3 lab identities from citations.** Some `measuring_lab_id` values
  name a cited reference's laboratory (e.g. "ref. 12 (HYC-0095)") because
  the paper did not name it; if such a laboratory coincides with another
  already in the dataset, two rows could be one laboratory.
- **The HYC-0060 round robin contributes little beyond 2 laboratories to
  the 1-bar CV**, because its per-participant 1-bar values are printed as
  interpolated (`value_kind = fitted_interpolated`) and the §11.0 row
  filters admit measured values only. Its one central BET area is counted
  once, not 14 times (`hycan.v1_rq3` docstring).

The §12 audit (references/v1_audit/) ran before any analysis result was
final: it found 0 errors in 60 rows (`references/v1_audit/score.json`), so
no follow-up rule fired and no value was re-checked.
