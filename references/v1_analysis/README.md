# v1.0 analyses (protocol §11)

This directory holds the §11 analysis outputs, each generated by
`scripts/v1_search/analysis.py` from the assembled dataset
(`data/processed/measurements_v1.0_computed.csv`); rerun the script to
regenerate them. Numbers live in the JSON files, not in this README.

| File | Content |
|---|---|
| `rq1_samples.csv` | The RQ1 primary analysis units (`hycan.v1_sets.rq1_samples`): one n_ex,max per sample with its laboratory and §11.0-eligible BET area. |
| `rq1.json` | RQ1: the primary mixed-model ratio to A_BET/500 with the t-based and laboratory-bootstrap 95% CIs, the §11 decision against [1/1.15, 1.15], the 95% prediction interval and variance components; the secondary ln–ln slope with reliability-corrected estimates; the exclusion ladder from all coded 77 K excess isotherms to the primary set; and the `p_at_nmax_bar` distribution with every value outside 10–60 bar listed. |

The §12 audit (references/v1_audit/) runs before any analysis result is
final: if its follow-up rule fires, the affected values are re-checked and
every analysis is regenerated by the same scripts.
